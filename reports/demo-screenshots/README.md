# Demo Screenshots

These screenshots are public-safe Vault966 workflow examples captured from the
real server-rendered UI using a temporary SQLite database seeded only with
fictional demo titles.

## Files

- `library-grid.png`: Library grid view with six synthetic movies.
- `review-flags.png`: Vault Health review workbench showing one synthetic flag.
- `flic-ranked-list.png`: Flic-ranked list view filtered to a synthetic sci-fi
  watch-night set.

## Data Boundary

The capture database was temporary and was not copied from the live Vault966
database. The visible movie titles, IDs, ratings, source filename, and review
notes are synthetic. The screenshots intentionally omit private collection
exports, local paths, logs, and personal profile names.
