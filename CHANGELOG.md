# Changelog

## v1.0.0

### Added
- New Discover experience with curated sections, refresh actions, and rotating highlights.
- Vault login flow with session support, per-profile credentials, and new login UI.
- Assistant API endpoint plus Siri Shortcut guide for voice usage.
- Vault update pipeline and helper scripts (backdrop backfill, genre normalization, server control).
- Role-aware profiles (admin/reviewer) with Collection Health gated to admin.
- Mobile install prompt and enhanced PWA metadata.

### Changed
- Navigation and layout polish across Discover, Library, Watchlist, and Detail views.
- Updated filters behavior and better mobile affordances.
- Logging improvements with profile-aware request labeling.

### Security
- Role-based access checks for sensitive routes.
- Session handling improvements for authenticated UI access.
