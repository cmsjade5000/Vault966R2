# PWA Asset Policy

`scripts/generate_brand_assets.py` owns the generated PWA icon and iPad startup images committed under `static/img`.

## Source Images

- `static/img/app-icon.png`: square master artwork used to regenerate web app icons.
- `static/img/splash-1024.png`: square master artwork used to regenerate iPad startup images.
- `static/img/profile-user-a.png` and `static/img/profile-user-b.png`: profile avatars used by the login screen; these are not generated by the PWA asset script.

## Generated Icons

The app ships the following generated icons:

- `android-chrome-192x192.png`: web manifest icon.
- `android-chrome-512x512.png`: web manifest icon.
- `apple-touch-icon.png`: iOS home screen icon.
- `apple-touch-icon-precomposed.png`: legacy iOS home screen icon.

`static/favicon.ico` is a hand-maintained browser favicon outside the generator.

## Generated Startup Images

Vault 966 is a landscape-first iPad PWA. The checked-in startup image matrix covers the iPad sizes referenced in `templates/base.html`:

- 12.9-inch iPad Pro portrait and landscape: `splash-2048x2732.png`, `splash-2732x2048.png`.
- 11-inch iPad Pro portrait and landscape: `splash-1668x2388.png`, `splash-2388x1668.png`.
- 10.5-inch iPad Pro portrait and landscape: `splash-1668x2224.png`, `splash-2224x1668.png`.
- 9.7-inch iPad and iPad Air 2 portrait and landscape: `splash-1536x2048.png`, `splash-2048x1536.png`.

Do not add iPhone, Android splash, alternate logo, or unused iPad images unless the app also adds runtime references and tests for that support.

## Change Contract

When changing PWA assets:

1. Update this policy first.
2. Update `scripts/generate_brand_assets.py` so generated targets match the policy.
3. Update `templates/base.html` or `static/site.webmanifest` when adding or removing runtime references.
4. Keep `tests/test_ipad_pwa.py` aligned with the policy.
5. Regenerate and commit only the files in this policy.
