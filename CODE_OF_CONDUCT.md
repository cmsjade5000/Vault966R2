# Code of Conduct

Vault 966 should be a practical, respectful project space for maintainers and
contributors.

## Expected Behavior

- Be direct, specific, and constructive.
- Assume good intent while still reviewing code rigorously.
- Keep discussion focused on the work and its impact.
- Respect privacy boundaries around local data, credentials, and logs.
- Accept maintainer decisions on scope, safety, and project direction.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private data, credentials, logs, database contents, or personal
  identifiers.
- Repeatedly derailing technical discussions after a maintainer decision.
- Pressuring maintainers to run unsafe commands or accept unreviewed bulk
  changes.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests;
or block contributors who make the project unsafe or unproductive. If a concern
cannot be raised publicly without exposing sensitive information, contact a
maintainer privately through GitHub.
